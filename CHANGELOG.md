# Changelog

## V0.1.0 — November 1, 2026

**First runnable prototype** of Pharmaceutical Stability Explorer.

- Static GitHub Pages application, independent from the medical-device Accelerated Aging Explorer.
- General-case ICH Q1A(R2) storage-condition selection and timepoint planning.
- Customizable planned study time points with required initial and final points.
- Drug-substance / drug-product distinction and product applicability gates.
- Batch/attribute measurement entry and measured trend visualization.
- Potential significant-change screening and conditional intermediate-study decision trace.
- Synthetic 3-batch, 48-observation starter dataset; no regulated or proprietary data.
- CSV and JSON import/export; Markdown evidence report.
- Responsive interface and GitHub Actions verification/deployment workflow.
- 25 automated logic tests passing; browser UI smoke tested using a local in-memory HTML/script harness (not a public GitHub Pages release).

**Validation status:** Functional prototype; neither scientific validation nor regulated computerized-system validation performed. No shelf life or retest period is calculated.
